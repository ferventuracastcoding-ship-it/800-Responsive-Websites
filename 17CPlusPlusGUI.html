C++ Linux GUI Project

Building a custom Linux desktop application using C++, graphical interfaces, and system programming.

🐧 Project Overview

This project creates a Linux-based GUI application using C++ that interacts with the operating system, manages files, displays system information, and provides a user-friendly interface.
