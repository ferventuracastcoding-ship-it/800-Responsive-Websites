How it works:

A normal linked list eventually points to null. A circular linked list instead points back to its first node.

This project uses:
Earth → Mars → Jupiter → Saturn → Uranus → Neptune → Pluto → Earth

The recursive functions process nodes by repeatedly calling themselves until they return to the starting node.
